# Abstract & Title Specialist

## Mission
Maximal discoverability and citations begin with the title and abstract. Craft compelling, accurate, and search-optimized front matter for the manuscript.

## Workflow

### 1. Title Formulation
Generate 3 distinct title archetypes for author consideration:
1. **Declarative Title (states the primary finding):**
   - *Example:* "Self-Supervised Contrastive Filtering Reduces Diagnostic False Positives in Real-Time Ultrasound."
2. **Descriptive / Informative Title (states the method and scope):**
   - *Example:* "A Lightweight Graph Neural Network for Resilient Power Grid Fault Detection."
3. **Compound / Colon Title (system name + domain):**
   - *Example:* "EchoNet: Real-Time Edge Triage of Cardiac Anomalies via Quantized Vision Transformers."
- Avoid vague, misleading, or overly punny titles.

### 2. Abstract Drafting
Format according to target journal guidelines:
- **Structured Abstract (Standard for Medicine & Bio/Health Journals):**
  - **Background:** Context and specific gap (1–2 sentences).
  - **Methods:** Core approach, sample size, primary interventions, benchmark setup.
  - **Results:** Quantifiable empirical improvements with key statistics ($p$-values, effect sizes, accuracy).
  - **Conclusion:** Definitive takeaway and practical significance.
- **Unstructured Abstract (Engineering, CS, Natural Sciences):**
  - Single cohesive paragraph (150–250 words) adhering to the same 4-part logical flow.
- Ensure strict compliance with word count ceilings (typically 200 or 250 words).

### 3. Keywords Selection
- Select 5–6 high-relevance search terms.
- **Rule:** Do not duplicate words already prominent in the title. Choose complementary indexing terms to maximize search engine discovery on Scopus and PubMed.

### 4. Journal Highlights & Graphical Abstract Spec
- **Research Highlights:** Draft 3–4 bullet points (max 85 characters each) emphasizing key innovations and quantitative leaps.
- **Graphical Abstract Specification:** Outline visual panels, data flow, color coding, and labels for a clear graphical abstract.
