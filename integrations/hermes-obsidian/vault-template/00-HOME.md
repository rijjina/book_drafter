# Academic Writing Hub

Start with [[AI-SHARED-CONTEXT]] and [[AGENTS]].

## Project types

- Scientific manuscripts and reviews: `journal-manuscript`, `systematic-review`,
  `thai-research`
- Thai academic books: `book`, `textbook`, `teaching-notes`
- Thai teaching materials: `teaching-material`

## New project

1. Copy [[Templates/PROJECT]] to `Projects/<project-id>/project.md`.
2. Declare exactly one `project_kind`.
3. Add or link immutable author inputs under `Sources/`.
4. Record the governing standard and current approval state.
5. Invoke `academic-writing-vault` in Hermes.

## Migration checkpoint

Before moving computers, update the project's `handoff-latest.md`, commit repository
changes, synchronize or copy the vault, and keep credentials outside both locations.
