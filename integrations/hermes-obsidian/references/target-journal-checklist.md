# Target Journal Readiness & Indexing Checklist

Use this checklist before submitting a manuscript to Scopus/Web of Science Q1–Q2 journals (Elsevier, Springer, IEEE, Wiley, MDPI, etc.).

---

## 1. Scope & Aims Alignment
- [ ] **Aims & Scope Verification:** The manuscript's central research questions explicitly match the journal's published scope.
- [ ] **Editor & Editorial Board Familiarity:** Key themes published by the journal in the last 24 months are appropriately acknowledged and cited.
- [ ] **Article Type Conformity:** Check whether the manuscript complies with the specific article type requirements (e.g., Original Research Paper, Review Paper, Brief Communication, Technical Note).

---

## 2. Structural & Word Count Constraints
- [ ] **Word Limit Compliance:** Main text word count is within journal limit (excluding abstract, references, tables, and figure captions).
- [ ] **Abstract Format:** Conforms to journal rules (unstructured vs. structured with Background, Methods, Results, Conclusion; word limit typically 150–250 words).
- [ ] **Keyword Requirements:** 4–6 relevant indexed keywords (avoiding words already prominent in the main title).
- [ ] **Figure/Table Limits:** Ensure total number of figures and tables does not exceed journal maximum (often 6–8 total for standard research papers).

---

## 3. Formatting & Declarations
- [ ] **Reference Style:** Correct style applied (e.g., IEEE numbered `[1]`, Elsevier Vancouver `[1]`, or Springer APA / Harvard author-date).
- [ ] **Cover Letter Prepared:** Specific, customized cover letter addressed to the Editor-in-Chief highlighting novelty, relevance to readership, and absence of prior publication.
- [ ] **Title Page / Blinded Manuscript:** If double-blind peer review is used, all author names, affiliations, acknowledgments, and grant numbers are completely removed from the main manuscript file.
- [ ] **Data & Code Availability Statement:** Explicit repository link (Zenodo, Figshare, GitHub with persistent release tag) provided with DOI.
- [ ] **CRediT Statement:** All authors assigned roles according to the CRediT taxonomy.
- [ ] **Declaration of Competing Interests:** Explicitly signed off by all authors.
- [ ] **Suggested Reviewers:** 3–5 qualified non-conflicted international peer reviewers identified (name, institutional email, affiliation, expertise area).
