# Teaching Material Integration

Use this route only for `TEACHING_HANDOUT` or source material dominated by
lecture transcripts, slides, course outlines, OBE/TQF, and teaching mappings.

1. Preserve all source files and create the teaching manuscript with
   `$thai-academic-teaching-material`.
2. Assess the stable manuscript with `$assess-thai-academic-manuscript` using
   `document_type: TEACHING_HANDOUT`.
3. Present the three-part assessment package and stop.
4. After the author names approved `RV-###` IDs, copy the bundled approval
   template outside the assessment package and record the decision.
5. Validate the assessment/approval handoff. Reject missing, unknown, or stale
   IDs and an input fingerprint that no longer matches.
6. Ask the teaching-material skill to revise only approved IDs while preserving
   the source mapping and instructor-specific explanation patterns.
7. Reassess material changes, especially BLOCKER/MAJOR, evidence, rights,
   alignment, or route-related changes.
8. Use `documents` to generate DOCX, render every page, and inspect Thai fonts,
   tables, images, page breaks, headers/footers, captions, and page numbers.

The teaching approval artifact is human authorization for the listed IDs only.
It is not a committee decision, route-readiness guarantee, or blanket approval
for later revisions.
